# galileoff-Dorkful
Açık kaynak istihbaratı ve bilgi toplama adımlarını otomatikleştiren bu proje, kullanıcı girdisine dayalı Google Dork sorguları üretir. Sistemdeki çok sayıda senaryo, hedef sisteme özel olarak derlenerek arayüz üzerinden çalıştırılır. Manuel veri toplama sürecini standartlaştırarak güvenlik araştırmalarını daha hızlı ve verimli bir hale getirir.
